Key teaching point

      

        free(auth) does not set auth to NULL.

        It only tells the allocator that the heap object may be reused. The variable auth still contains the old address,
        so it becomes a dangling pointer.
      

      

        After reset, any dereference such as auth->auth is invalid. If a later allocation
        reuses that chunk, the stale pointer may now interpret new attacker-controlled data as the old structure.
      

      

        Defensive takeaway for students: after freeing a pointer that may still be referenced later, a common mitigation is
        free(auth); auth = NULL; and then checking before use.
